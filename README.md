🎭 KalaConnect – Connecting People Through Art and Culture

📌 About the Project

KalaConnect is a web-based platform designed to connect students and instructors through traditional arts and creative activities. It provides a single platform where users can explore Bharatanatyam, singing, and craft classes, view instructor profiles, and join online classes.

The main aim of KalaConnect is to encourage creativity, make art learning more accessible, and promote traditional cultural activities through technology.

🎯 Objectives

- To provide a platform for learning different art forms.
- To connect students with instructors.
- To display class details, instructor profiles, and timings.
- To allow students to register, log in, and manage their profiles.
- To support online class participation through meeting links.
- To encourage communication and feedback between students and instructors.

✨ Features

- Home Page: Introduces KalaConnect and its purpose.
- About Page: Displays the mission, vision, and objectives of the project.
- User Registration and Login: Allows users to create accounts and log in.
- User Profile: Displays user information and joined classes.
- Classes: Shows Bharatanatyam, singing, and craft classes with schedules.
- Instructor Profiles: Displays instructor names, specializations, and experience.
- Online Class Joining: Allows students to open video meeting links.
- Meeting Link Sharing: Supports sharing class meeting details through WhatsApp.
- Assessment: Can be extended to support assignment submissions and instructor reviews.
- Attendance: Can be extended to track student attendance.
- Event Booking: Can be extended to support registration for art and cultural events.
- Feedback and Ratings: Can be extended to collect student feedback.

🛠️ Technologies Used

- HTML5 – Structures the web pages.
- CSS3 – Provides styling, layouts, and responsive design.
- JavaScript – Implements interactive features and page functionality.
- Browser localStorage – Stores demonstration account and class data locally.
- Google Meet – Supports online class meetings.
- WhatsApp – Enables sharing class meeting links.

🚀 How to Run the Project

1. Download or clone the KalaConnect repository.
2. Open the project folder in Visual Studio Code.
3. Check that all HTML, CSS, JavaScript, and image files are saved in the correct locations.
4. Install the Live Server extension in Visual Studio Code if needed.
5. Open "index.html" and select Open with Live Server.
6. Register an account and log in to explore the website.
7. Open the Classes page to view class details and try joining a class.

👩‍🎓 How to Use KalaConnect

1. Open the home page.
2. Register a new account.
3. Log in using your account details.
4. View your profile and explore available classes.
5. Select Bharatanatyam, singing, or craft.
6. View the instructor profile and class schedule.
7. Join the class using the available meeting link.
8. Share meeting details through WhatsApp when required.

🔒 Current Limitations

- The current demonstration may use browser localStorage, which does not automatically synchronize data between different devices.
- Online meetings require valid meeting links created by instructors.
- Features such as shared-database synchronization, attendance management, assessment reviews, and event booking may require further implementation.
